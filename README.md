# vcpe.dev

The front page of https://vcpe.dev/: the root GitHub Pages site of the boardfarmdevs account. Every
boardfarmdevs project site is served under it as a path, for example https://vcpe.dev/easymesh-labs/.

- `index.html`: the front page, leading to the EasyMesh labs and listing the project sites.
- `404.html`: the earlier vcpe.dev notes moved to https://revs.dev/; links to their paths
  (`/docs/`, `/lxd/`, `/rssfree/`, ...) are sent there. Anything else gets a not-found page.
